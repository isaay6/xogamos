# Kit ENS (categoría básica)

Documentos para que un concello ou unha Deputación que opere Xogamos poida declarar a conformidade
do seu sistema co **Esquema Nacional de Seguridade** (Real decreto 311/2022), categoría **básica**,
mediante autoavaliación, segundo a guía CCN-STIC 809.

**Quen declara.** A conformidade é do **sistema** que opera a entidade (o servidor, as persoas, os
procedementos e o software), non do software por si só. Xogamos achega as medidas técnicas; a
entidade completa as organizativas e asina.

| Documento | Para que serve |
|---|---|
| [analise-riscos.md](analise-riscos.md) | Análise de riscos simplificada (op.pl.1) e categorización do sistema |
| [declaracion-aplicabilidade.md](declaracion-aplicabilidade.md) | Cada medida do Anexo II que aplica en categoría básica: que achega o produto e que fai a entidade |
| [declaracion-conformidade.md](declaracion-conformidade.md) | Modelo de declaración para asinar e publicar na sede electrónica |

Detalle técnico das medidas: [../seguridade.md](../seguridade.md).

**Orde recomendada:** 1) revisar a análise de riscos co sistema real; 2) completar a columna da
entidade na declaración de aplicabilidade; 3) asinar e publicar a declaración de conformidade.
Revisión: anual ou ante cambios importantes no sistema.

> Estes documentos son unha base de traballo. A entidade debe contrastalos co texto vixente do
> RD 311/2022 e coas guías do CCN antes de asinar.
